# 중복 이미지 정리

SHA-256과 실제 파일 바이트가 같은 이미지·SVG 15개 그룹을 확인해 중복 23개를 제거했습니다.
총 51,256,855바이트(48.88MiB)를 줄였습니다. 압축·크기 변경·재인코딩 없이 원본 한 개씩 유지합니다.

코드의 이미지 경로는 유지한 원본을 참조합니다. 회사소개 사업영역의 이미지별 화질 설정과 모든 화면의 자르기·배치는 유지합니다.
반도체 칠러 사례의 대표 사진 경로는 이전 DB 초기 사진 형식 판별에 쓰이므로 기존 경로를 유지합니다.

삭제한 경로와 유지한 원본의 대응은 `config/image-aliases.json`에 있습니다.
`next.config.ts`의 내부 rewrite가 이전 이미지 URL을 원본으로 연결하므로 기존 DB 사진 경로와 외부 링크도 유지됩니다.
DB·S3를 일괄 수정하거나 삭제하지 않습니다. 페이지 주소에 대한 기존 ASP 리디렉션도 유지합니다.

배포 후 회사소개, 냉각탑·저온저장고·항온항습기, 메인 시공사례와 관리자 기존 사진을 확인합니다.
이전 사진 URL의 직접 요청과 Next Image 최적화 요청이 모두 성공해야 합니다.
DB에 오래된 주소가 남아 있을 수 있으므로 alias는 단순 미사용 경로로 간주해 삭제하면 안 됩니다.
