# 관리자 화면 통계 제외

홈페이지와 관리자는 서로 다른 루트 레이아웃을 사용합니다.

- `app/(public)/layout.tsx`: 홈페이지 공통 화면과 GA4·Google Ads·네이버·전화 전환 추적.
- `app/(management)/layout.tsx`: 관리자·로그인 화면. 분석·광고 스크립트와 전화 추적 리스너를 포함하지 않음.
- 공통 메타데이터는 `src/lib/site-layout-metadata.ts`, 스타일은 `app/globals.css`를 사용함.

괄호 폴더는 URL에 포함되지 않으므로 홈페이지 주소, `/admin`, `/admin/login`, API·Cognito 콜백 주소는 유지합니다.
서로 다른 루트 레이아웃으로 이동하면 전체 문서가 다시 로드되어 홈페이지에서 이미 실행한 추적 스크립트도 관리자 화면으로 이어지지 않습니다.
단순 조건부 컴포넌트 숨김만으로 이미 로드된 Google 자동 페이지 추적이 남는 문제를 피합니다.

관리자 로그인 여부로 일반 홈페이지 방문을 제외하는 기능은 아닙니다. 관리자도 일반 홈페이지를 열면 일반 방문으로 집계됩니다.
기존 GA4 측정 ID·광고 전환 ID·네이버 계정, 정상 문의 접수와 전화 클릭 전환 처리는 그대로 유지합니다.

배포 후 개발자 도구 네트워크에서 `/admin/login`·`/admin`은 Google/Naver 분석 요청이 없는지 확인합니다.
홈페이지와 견적문의 화면은 분석 스크립트가 계속 포함되는지 확인합니다.
광고 전환 실검증을 위해 허위 견적문의나 시험 메일을 전송하지 않습니다.
